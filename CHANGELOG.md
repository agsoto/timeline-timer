## [0.1.0] - 2026-08-01

### Added

- Plain-text agenda parsing with flexible duration formats.
- Edge-docked horizontal and vertical layouts with directly resizable dimensions.
- Always-on-top timing with continuous progress, remaining time, and playback state shown by the playhead.
- Compact mode with configurable labels, counters, edge controls, and improved contrast over bright content.
- Keyboard and mouse controls for editing, reordering, timing adjustments, and navigation.
- Persisted layout, behavior, and accent-color settings with reset controls.
- Live custom CSS overrides.
- Circular transparent application icons and automated desktop release builds.
- Windows development and troubleshooting guidance.
