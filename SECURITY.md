# Security Policy

Before the first release, security fixes are made on the `main` branch. After that, only the latest release is supported.

Use **Report a vulnerability** on the repository's Security tab. Include reproduction steps, the affected version and platform, and the likely impact. Do not include vulnerability details in a public issue. If private reporting is unavailable, open an issue asking for a private contact without describing the vulnerability.

Reports are handled on a best-effort basis and investigated privately.
